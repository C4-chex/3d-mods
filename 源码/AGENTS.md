# CT3D 当前开发目录

- 用户指定后续新增功能、配置、文档与检查工具均放在 n2。上级 CT3D 为历史工作副本，不再同步新增功能；Python + HTML 与 WRONG 归档保留。
- 遵守本目录的 CT3D_产品原则.md：空间和像素正确性优先，原始影像只读，CT HU 与 MR 强度严格区分，本地运行，AI 为可选独立模块。
- 开发顺序：关注位置收藏、关联研究记录包、分割定量统计、同患者 CT/MR 配准与对照、任务阅片布局。未通过验证的功能不得在 README 中写成已完成。
- 每次大修改后按用户要求检查正确性并复现实际入口与操作。发布 ZIP 使用白名单，源码包排除内核二进制、影像、数据库、缓存、日志和本地输出；独立成品必须包含所需内核运行库。
- 主启动入口为本目录的启动 CT3D.bat；内部脚本用 ASCII 内容、CRLF 换行，避免中文路径字面量编码问题。主入口仅启动 runtime/CT3D.exe；没有编译完成时明确报缺少应用，不自动回退外部 Slicer。旧开发入口在 tools/launch-development.bat。desktop 为独立应用工程；未完成编译不得宣称独立应用已通过验收。
