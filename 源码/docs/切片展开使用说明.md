# 切片展开窗口

更新：2026-10-13。此功能用于移开切片遮挡、标记和回到原图核对。它不是配准、切片位置校正或提高采集分辨率的工具。

## 打开

1. 在主窗口导入 DICOM 文件夹，选择并载入一套 MR 或 CT 序列。
2. 在四视图右下方 3D 视窗的“切片展开”按钮上点击，打开独立窗口。
3. 再次点击同一按钮会将已有窗口置前，不会创建第二份窗口。

窗口大小随可用屏幕限制；缩小窗口时，左侧操作栏可滚动，避免按钮被裁掉。

新序列默认显示全部采样切片。已有记录的序列会恢复上次保存的偏移、隐藏状态、显示范围和 tag。程序默认将记录保存到用户目录 `CT3D/output/slice-stack/`；若配置 CT3D_WORKSPACE_ROOT，则在该工作目录的 output 下保存。

## 观察和移动

- **旋转观察**：模式列表选择“旋转观察”，左键拖动旋转视角。
- **移动切片**：选择“移动切片（平面内）”，左键按住可见切片并拖动。移动仅沿该切片自身的两个平面方向；不会改变层间真实距离和源图坐标。
- **精确调整展示偏移**：用“选中切片”指定层，再设置横向、纵向偏移。单位为毫米，但这些数值是展示偏移，不是结构的真实位移。
- 右键拖动缩放、中键拖动平移视角；滚轮也可缩放。视角复位按当前可见切片范围居中。
- 黄色轮廓表示选中切片。已移动时显示原位置灰色轮廓和连接线，并标注“展示已偏移”。

全部切片初始重叠是正常的；它们遵循原始空间位置。前方切片会挡住后方切片，可以移开前方层，也可以使用下列显示控制。

## 控制遮挡

- “隐藏选中切片”：临时隐藏指定层，不删除图像。
- “显示层范围”：填写起始和结束层，范围包括两端，起始层不能大于结束层。
- “只看选中层”：便于检查或添加 tag。
- “恢复全部显示”：恢复全部层的可见性和范围，保留展示偏移及 tag。
- “当前切片复位”：只清除当前层的展示偏移。
- “全部复位”：清除所有展示偏移，并恢复全部显示；保留 tag。
- “撤销上次操作”：支持最近 50 次移动、显示和 tag 编辑操作。本次窗口关闭后不保留撤销历史。

## 添加和使用 tag

1. 选中目标层。若被遮挡，可先使用“只看选中层”或移开其他层。
2. 输入文字备注，选择“添加 tag”模式。
3. 在切片目标位置点击左键。窗口显示标记点，左侧列表出现备注和层号。
4. 点击列表项，主窗口十字线和三切面返回该点的**原始空间位置**；独立窗口同时选中目标层并确保它在显示范围内。
5. 修改备注时先选中列表项，在备注框填写新文字，再点击“修改选中 tag 备注”。删除操作可以通过撤销恢复。

tag 绑定切片内位置和原始 RAS 毫米坐标，不绑定拖动后的屏幕位置。拖动切片后标记点随展示移动，但回到主窗口核对的位置不变。最多 1000 个 tag，每条备注最多 500 字符。

每套序列的记录总大小限制为 2 MiB；超过时提示减少 tag 或缩短备注，不覆盖已保存文件。

## 保存、切换和退出

操作完成后自动保存；也可点击“保存当前状态”。拖动过程中不连续写磁盘，松开后保存。关闭窗口和切换序列前会保存，正常退出程序时也会清理窗口资源。

主窗口切换序列时，独立窗口跟随切换；不同序列记录隔离。序列、像素内容或当前空间几何不一致时，不会把其他记录套用到当前影像。记录文件名使用内容关联键，不自动写入患者姓名和 ID；用户自填备注应自行避免身份信息。

保存失败时请查看窗口底部提示，确认 output 可写；失败不会静默覆盖已有文件。损坏或不匹配的记录会保留原文件，窗口进入只读状态，可以关闭或切换序列。若同一记录被其他程序修改，当前窗口拒绝覆盖；重新打开窗口后再操作。

## 准确性与限制

- 最近邻显示，使用已载入原始采样；不为了消除台阶填充层间内容。
- 平面位置包含当前采集几何变换；变换后单张切片若不能保持平面，明确拒绝按原始平面展开，不伪造平直图像。
- 展示偏移不能用于解剖距离测量。长度测量仍在主窗口进行。
- 新窗口共享原有体数据，不复制整套体像素；切片显示仍会使用额外的图形资源。很多层或大矩阵的性能需要在目标机器上实际检查；首轮样本为 20 层 MR 和 140 层 CT 体模。
- 当前仅随 CT3D 自己的导入/切换流程联动。打开窗口后应避免在其他模块修改影像像素或父变换；修改后关闭并重新打开窗口，重新核对关联。

技术实现参考官方 [独立三维视窗示例](https://slicer.readthedocs.io/en/latest/developer_guide/script_repository.html#show-a-3d-view-outside-the-view-layout) 和 [VTK 切片映射器](https://vtk.org/doc/nightly/html/classvtkImageSliceMapper.html)。
