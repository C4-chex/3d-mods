# 关注位置收藏：减少重复定位

## 用途

在同一轮阅片中反复返回某个结构，并恢复当时的窗宽窗位、三切面方向与缩放、三维相机、体渲染预设和裁剪范围。收藏只保存轻量显示状态，不复制影像体素，也不修改 DICOM。

## 操作

1. 使用 n2 的“启动 CT3D.bat”，导入 DICOM 文件夹并载入目标序列。
2. 在切片上按住 Shift 移动鼠标，定位关注结构。收藏位置以十字线的世界 RAS 毫米坐标为准。仅滚动切片不一定改变十字线，请先明确定位。
3. 调整窗宽窗位、切面缩放、三维视角和裁剪范围。
4. 展开“关注位置收藏（本次会话）”，输入结构或研究备注，点击“收藏当前位置与视图”。备注最多160个字符；不填写患者身份信息。
5. 可继续浏览或载入其他序列。单击列表中一个收藏，返回其来源影像并恢复保存的显示状态，不必手动切换序列和调节参数。
6. 选中不再需要的收藏，点击“删除选中收藏”。

## 边界

- 当前是会话内收藏，关闭程序或清空场景后不保留；最多100项。普通 MRB 场景保存不会保存此版收藏列表。跨会话持久化与研究记录包尚待实现。
- 来源影像必须仍在场景中。移除来源、修改体素/几何或变换链后拒绝返回，防止错误空间对应。不会自动重新读取已经移除的影像。
- 收藏不保存分割编辑历史，不回滚测量或分割，不保存其他模块的透明叠加布局。
- 插值和外观平滑只改善显示，收藏不会提高原始采样精度。
- 此版真实数据验收覆盖现有 MR 样本；人体 CT 和配准后的非线性变换流程仍需专项验证。

## 复现检查

使用已配置的 launch.bat 带参数运行：

```bat
launch.bat --testing --python-script "%CD%\tools\verify_bookmarks.py"
```

该脚本使用开发机原 MR 样本目录，因此发布后应替换为自己的已授权样本路径。结果写入 verification/bookmarks/results.json。检查包括实际载入、按钮收藏、跨序列返回、显示恢复、来源被移除/变换改变时拒绝返回、删除、清空及源像素/DICOM校验。
