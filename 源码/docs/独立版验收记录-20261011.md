## 本轮修正

1. 源码归档没有 Git 日期，导致打包配置失败：补充固定提交对应的真实日期与明确的归档来源记录。
2. MRML 场景修订宏需要数值，文字修订标识导致 C++ 编译失败：场景使用本地构建编号 `20261011`，归档来源标识独立保留。
3. 收藏快照的 `CreateNodeInstance()` 没有在 Python 包装中自动移交新对象初始引用，删除后仍保留对象，触发退出泄漏弹框：改为带所有权标记的 `NewInstance()`；模块清理时清除收藏。
4. 原验收只读取脚本通过报告，没有验证进程退出，漏掉退出弹框：增加真实退出等待和退出码检查，泄漏检测失败会停止后续检查。
5. 验收脚本的临时 VTK 引用延续至退出：使用局部作用域和回收，不以测试引用妨碍退出。
6. 首次显示没有再次应用面板比例：增加 showEvent 初始化；实际左右宽度比例约 `0.61785:1`。
7. 验收窗口尺寸超过屏幕以及布局尚未稳定：限制测试窗口尺寸，等待布局完成后记录收藏基准，三个切面视野恢复值一致。

曾经出现的用户截图报错确实来自本轮收藏验收。失败记录保留在 `verification/native-exit-leak-20261011.json` 和相关退出失败报告中。此前只有功能报告通过的记录，不作为最终验收证明。
