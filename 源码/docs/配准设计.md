# CT/MR 同患者配准接口约束

当前范围是 CT 独立阅片；软件配准作为后续阶段。本文件约束后续扩展，避免叠加时丢失医学影像坐标。

## 数据与坐标

- CT 与 MR 始终保留为两个独立的 MRML volume 节点和两个独立的原始 DICOM 序列；不得先把像素矩阵当作相同网格。
- 配准输入需要由操作者明确选择固定影像和移动影像，并在开始前确认两者属于同一患者。只用本地患者/检查索引做提示，不把相同姓名或相同坐标当作配准证据。
- 配准结果保存为独立的线性变换节点，连同固定/移动节点引用、算法与参数、创建时间和人工核对状态；源体素和源文件只读，不硬化变换覆盖原始影像。
- 保存/重开场景后检查变换方向、坐标系（Slicer RAS 与 DICOM LPS）和数据引用仍一致。

## 操作者核验与显示

- 操作者可在叠加前后查看轴位、冠状位、矢状位和 3D；至少提供透明度或棋盘格/擦除对照，以及可逆的变换启用/停用。
- 配准后需检查解剖标志在三正交切面中的对齐，显示变换状态和提示；不能仅凭优化器收敛或数值分数宣称配准正确。
- 无足够重叠区域、疑似不同检查/患者、明显局部形变或失败时，明确报告未完成并保留未配准视图。
- CT 与 MR 强度物理含义不同；融合显示不改变 MR 强度，也不把 MR 标为 HU。

## 实现边界

后续可调用 Slicer 提供的注册模块/逻辑创建可编辑的变换节点，而不是在 CT3D 内另造一套坐标或重采样管线。自动配准、刚性/仿射选择、人工标志点、质量指标和持久化行为须单独设计并用同患者配对数据验证；本阶段未实现配准。
