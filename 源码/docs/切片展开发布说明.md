# CT3D 切片展开版 · 2026-10-13

完整解压压缩包，进入同名文件夹，双击 CT3D.exe。无需另装 Slicer、Python 或开发工具。

载入 MR/CT 后，点击主窗口右下方 3D 视窗中的“切片展开”。新窗口支持原始采样平面排列、平面内移开遮挡、显示范围与隐藏控制、撤销和复位，以及原图位置 tag 的保存和恢复。详细操作见随包的“切片展开使用说明.md”。

切片移动仅用于展示，不修改原图，也不提高采集分辨率。tag 默认保存在用户目录 CT3D/output/slice-stack。

本包沿用 2026-10-11 已验收的原生程序和运行库，新增功能属于 CT3D 脚本模块更新。因此应用版本信息仍显示原生构建日期，不代表重新编译内核。更新后的成品需要独立进行运行与功能检查；验收记录随源码和开发日志保留。另一台干净 Windows 机器尚未验收。
